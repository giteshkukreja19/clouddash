☁ AWS Configuration Guide
Step-by-step instructions to connect your S3 bucket
Step 1   Create an S3 Bucket
  1. Go to AWS Console → S3 → Create Bucket
  2. Enter a globally unique bucket name (e.g. myname-cloud-dashboard-2024)
  3. Choose the region closest to you (e.g. us-east-1)
  4. For public files: uncheck Block all public access and add a bucket policy
  5. For private files (recommended): keep Block Public Access ON, use pre-signed URLs
Step 2   Create an IAM User
  1. Go to AWS Console → IAM → Users → Create User
  2. Username: cloud-dashboard-app
  3. Permissions: Attach the policy below (least privilege)
  4. Create Access Key → Download CSV
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": [
      "s3:PutObject",
      "s3:GetObject",
      "s3:DeleteObject",
      "s3:ListBucket"
    ],
    "Resource": [
      "arn:aws:s3:::YOUR-BUCKET-NAME",
      "arn:aws:s3:::YOUR-BUCKET-NAME/*"
    ]
  }]
}
Step 3   Configure Environment Variables
# Edit your .env file:
AWS_ACCESS_KEY_ID=AKIA...
AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI...
AWS_REGION=us-east-1
S3_BUCKET_NAME=myname-cloud-dashboard-2024

# Restart Flask after changing .env
python app.py
Production   EC2 IAM Instance Role (Best Practice)

On EC2, never use Access Keys. Attach an IAM Role to the instance instead — boto3 auto-detects it.

  1. IAM → Roles → Create Role → EC2
  2. Attach the same S3 policy as above
  3. EC2 → Instances → Actions → Security → Modify IAM Role
  4. Select the role — no keys needed in your .env file!
